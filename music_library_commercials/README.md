# Commercials

Drop ad/jingle audio files here (same supported extensions as
`music_library/`) and hit "Rescan Library" to pick them up. These play
at random regardless of which station is tuned - a separate pool, never
one of the folder-per-station directories under `music_library/`.

See `docs/AI_MUSIC_PROMPT.md`'s "Entertainment Box" advertisement jingle
section for a ready-to-use ad-copy + music-generation prompt, and
`CLAUDE.md`'s "Stations, commercials, and static" section for how the
scheduling works.
