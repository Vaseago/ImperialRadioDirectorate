# Music library

Drop audio files here (`.mp3`, `.ogg`, `.oga`, `.flac`, `.wav`, `.m4a`,
`.aac`) and hit "Rescan Library" in the app to pick them up.

For V1, this is meant to hold AI-generated tracks produced from
`docs/AI_MUSIC_PROMPT.md` - original ambient music, not extracted or
sampled from anything, so there's no copyright concern. See
`CLAUDE.md` for the full legal reasoning.
